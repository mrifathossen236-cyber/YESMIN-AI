# YESMIN AI — Advanced Android Starter

This repository contains the YESMIN AI Android MVP source plus the advanced implementation roadmap and status checklist.

## Build APK with GitHub Actions
1. Extract this ZIP.
2. Create a GitHub repository named `YESMIN-AI`.
3. Upload the **contents** of this folder to the repository root. `settings.gradle.kts` must be at the root.
4. Open Actions and run **SR AI Android APK** (or push to `main`).
5. Download the APK artifact from the successful workflow run.

## Gemini setup
Install the APK, open Settings, and enter a Gemini API key and a model name available to your Google AI Studio project.

## Important
The current source is an MVP, not the completed advanced feature set. See `IMPLEMENTATION_STATUS.md` and `PROJECT_ROADMAP.md`. API keys stored on a client device are not suitable for public distribution; use a secured backend proxy for a production release.
